## 项目简介
本项目旨在为 MoonBit 生态提供一个纯 MoonBit 实现的轻量级符号计算内核。不同于 Lua-Flow 等专注于数值计算的库，本项目将数学表达式作为数据结构，提供符号化简、符号求导和基础积分能力，可运行于 wasm、js 和 native 等多后端。

## 核心功能范围
- 定义完整的符号表达式类型（常量、变量、加减乘除、幂、三角函数、指数对数等）
- 实现符号化简引擎（常数折叠、合并同类项、恒等式消去等）
- 实现符号求导（涵盖乘积法则、商法则、链式法则、幂法则）
- 实现基础符号积分（多项式、三角函数、指数函数）
- 提供表达式格式化输出（将 AST 转为可读字符串）
- 支持自定义错误处理（无法解析或无法积分的表达式抛出 SymbolicError）
- 纯 MoonBit 实现，零 FFI 依赖，兼容各主流后端

## 预期使用场景
1. **AI 与自动微分**：为 MoonBit 机器学习框架提供符号求导基础，生成梯度计算图。
2. **数学教育工具**：为 MoonBit 构建的在线计算器或 IDE 插件提供公式化简和步步求导功能。
3. **编译器优化**：在 MoonBit 编译期对常量表达式或代数式进行化简，减少运行时计算开销。
